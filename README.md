# Dodekanisa Glass - Systems & Engineering

A premium, localized web platform for **Dodekanisa Glass**, specializing in the resale of high-performance glass products and professional installation services across the Dodecanese.

## Tech Stack

- **Framework**: React 19 + Vite
- **Routing**: React Router 7
- **Styling**: Tailwind CSS (with Glassmorphism utilities)
- **Animations**: GSAP (GreenSock Animation Platform)
- **Icons**: Lucide React

## Project Architecture

- **Multi-Page**: Unified site structure featuring Home, Products, Portfolio, About, FAQ, and Contact pages.
- **Glass-First UI**: Minimalist, industrial-luxury aesthetic with deep navy (#2C3E50) and teal accents.
- **Unified Logic**: Simplified code structure focused on a dual "Product + Installation" business model.

## Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

```bash
# Clone the repository and navigate into it
cd greek-glass-systems

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

## Features

- **17+ Service Categories**: Dynamic catalog of specialized glass systems.
- **SEO Optimized**: Dynamic page titles and semantic HTML.
- **Responsive**: Mobile-first design for all screen sizes.
- **UX Polish**: Automatic "Scroll to Top" navigation and a floating "Back to Top" assistant.
